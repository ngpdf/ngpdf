'@ngpdf/core': minor
---

Adds `ng add @ngpdf/core`, so you can start with one command instead of setting things up by hand. It installs the package and writes an example document to your application, ready to render. With `--demo-route` you also get a `/pdf-demo` page with a Download PDF button, so you can see a PDF in the browser right away. `--project` picks the application and `--path` picks the folder. Your existing files are never overwritten.
