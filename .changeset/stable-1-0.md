First stable release. From 1.0 on, the public API follows semantic versioning: breaking changes to the elements, their inputs, the style properties, `PdfRenderer` and the server entry point only come in a new major version. Nothing breaks in this release by itself; it groups the v1.0 features listed below (pdf-svg, pages that grow with their content, row views that split across sheets, `min-presence-ahead`, every standard paper size and page sizes with units).
