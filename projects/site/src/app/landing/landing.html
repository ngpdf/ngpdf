Write PDFs as Angular components.

ngpdf renders a normal Angular component to a real PDF, in the browser: selectable text, tables with repeating headers, page breaks and page numbers. No server, no screenshots, and about 2 KB on your first load.

01 · Write

A document is a component

Lay it out with the pdf-* elements and the CSS you already know: flexbox, padding, borders, colors. Bind data with inputs and signals, format it with pipes, loop over it with @for.

Then render it with one call, wherever you can inject a service.

02 · Try it

Edit it. It renders again, right here.

This invoice is an Angular component on this page. Change its inputs and ngpdf lays it out, paginates it and writes a new PDF in your browser.
